# Установка Home Assistant OS на PiPO X9s

## Шаг 0. Что стоит на X9s сейчас — неважно

На коробке может стоять Windows, Linux с чужим паролем, что угодно. Пароль не нужен: в шаге 3 диск стирается целиком.

Единственное, что надо узнать — 64-битный ли UEFI (прошивка, которая грузит систему). У 2-гиговых коробок на Z8350 он часто 32-битный, и HAOS на таких не грузится. В BIOS (Aptio, вкладка Main) разрядность не показана: `UEFI 2.4` это версия стандарта, не разрядность.

Проверка — сам шаг 2: HAOS с флешки либо загружается, либо нет. Ничего не стирается, риска ноль.

Если на коробке Windows и лень делать флешку: `msinfo32` → «Тип системы». `x64-based PC` значит HAOS встанет, `x86-based PC` значит нет.

Ещё посмотри сзади коробки, есть ли разъём RJ45 (сетевой, как у роутера). Сервер должен сидеть на проводе.

## Шаг 1. Флешка с HAOS

Нужна USB-флешка от 8 ГБ. **Всё на ней сотрётся.**

1. Скачать образ: https://github.com/home-assistant/operating-system/releases → файл `haos_generic-x86-64-XX.X.img.xz`
2. Скачать [balenaEtcher](https://etcher.balena.io/)
3. Etcher → Flash from file → выбрать `.img.xz` → выбрать флешку → Flash

## Шаг 2. Пробный запуск с флешки, Windows не трогаем

Идея: HAOS умеет работать прямо с флешки. Загружаемся с неё и смотрим, взлетает ли. Windows на eMMC остаётся целой, если что — просто вынул флешку.

1. Выключить X9s. Воткнуть флешку, Ethernet-кабель, Sonoff-стик через удлинитель.
2. Включить и сразу долбить `Del` (если не сработало — `Esc`, потом `F7`). Должен открыться BIOS или меню загрузки.
3. В BIOS:
   - Security → **Secure Boot → Disabled**. HAOS с включённым Secure Boot не грузится.
   - Boot → первым поставить USB-флешку. Или в Boot Menu (F7) выбрать её один раз.
   - Save & Exit (F10)
4. На экране X9s побегут строки, потом появится логотип HA и текст `ha >`. Это нормально, так и должно быть. Первый запуск качает контейнеры, 5-15 минут.
5. На телефоне или ноутбуке в той же сети открыть `http://homeassistant.local:8123`. Если не открывается — найти IP коробки в роутере и открыть `http://<ip>:8123`.
6. Видишь «Preparing Home Assistant» → всё работает. Дождаться, создать пользователя.

Если на шаге 4 чёрный экран, ошибка `no bootable device`, или BIOS не видит флешку — **UEFI 32-битный**. Иди в `06-plan-b-docker.md`, раздел «Debian на X9s».

## Шаг 3. Переезд с флешки на eMMC

Работать с флешки постоянно можно, но флешки дохнут. Переносим на встроенный диск.

Способ через Ubuntu Live (самый понятный):

1. Вторая флешка. Записать на неё Ubuntu Desktop через Etcher: https://ubuntu.com/download/desktop
2. Загрузиться с неё на X9s, выбрать «Try Ubuntu»
3. Скопировать файл `haos_generic-x86-64-XX.X.img.xz` на эту же флешку заранее, или скачать в Ubuntu через браузер
4. В Ubuntu открыть терминал (Ctrl+Alt+T):
   ```bash
   lsblk
   ```
   Найти eMMC: это `mmcblk0` или `mmcblk1`, размером ~29G или ~58G. **Не `sda`/`sdb` — это флешки.**
5. Записать образ. Внимательно с именем диска, команда стирает всё на нём:
   ```bash
   xzcat ~/Downloads/haos_generic-x86-64-*.img.xz | sudo dd of=/dev/mmcblk0 bs=4M status=progress conv=fsync
   ```
6. Выключить, вынуть обе флешки, в BIOS поставить загрузку с eMMC. Включить. Дальше как в шаге 2, п. 4-6.

Windows после этого нет. Если она нужна — сделай образ диска до шага 5, но честно, зачем она на этой коробке.

## Шаг 4. Первичная настройка HA

1. Создать пользователя (это админ)
2. Название дома, координаты, часовой пояс
3. HA покажет найденные устройства в сети — пока пропускай
4. Настройки → Система → Сеть: проверить, что IP получен по проводу. Лучше зафиксировать IP на роутере по MAC-адресу.

Дальше: `03-zigbee.md`.

## Если что-то не так

| Симптом | Что делать |
|---|---|
| BIOS не открывается | Пробовать Del, Esc, F2, F7 по очереди, зажимать сразу при включении |
| Флешки нет в списке загрузки | Secure Boot включён, или флешка записана криво. Перезаписать в Etcher |
| Грузится, но нет сети | Только Wi-Fi? Нужен провод. Проверить кабель и порт на роутере |
| `homeassistant.local` не открывается | Открыть по IP. Windows иногда не резолвит `.local` |
| Экран X9s мигает/чёрный после логотипа | Нормально. Управление через браузер, экран не нужен |
