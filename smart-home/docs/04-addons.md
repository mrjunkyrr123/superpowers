# Аддоны: Mosquitto и Zigbee2MQTT

Аддон = программа внутри HAOS, ставится кнопкой. Настройки → Аддоны → Магазин аддонов.

## 1. Mosquitto broker

1. Магазин аддонов → найти «Mosquitto broker» → Установить
2. Ничего не настраивать. Запустить. Включить «Запускать при загрузке» и «Сторожевой таймер»
3. Создать пользователя для MQTT: Настройки → Люди → Пользователи → Добавить. Имя `mqtt`, пароль сложный, **снять галку «Может входить только из локальной сети»** не надо, оставить как есть. Этот пользователь нужен только аддонам.
4. Через минуту HA сам покажет «Обнаружено: MQTT» в Настройки → Устройства и службы. Нажать Настроить → Отправить. Логин и пароль подставятся сами.

## 2. Zigbee2MQTT

Его нет в стандартном магазине, надо добавить репозиторий:

1. Магазин аддонов → три точки справа сверху → Репозитории → вставить:
   ```
   https://github.com/zigbee2mqtt/hassio-zigbee2mqtt
   ```
2. Найти «Zigbee2MQTT» → Установить (не Edge-версию)
3. **До запуска** — вкладка «Конфигурация». Заполнить по образцу из `haos/zigbee2mqtt-addon-options.yaml`. Обязательные два поля:
   - `serial.port` — путь к стику. Взять из Настройки → Система → Оборудование → «Все оборудование» → `ttyUSB` → скопировать `/dev/serial/by-id/usb-ITead_...`
   - `serial.adapter` — `zstack` для ZBDongle-P, `ember` для ZBDongle-E
4. Секцию `mqtt` оставить пустой: аддон сам подключится к Mosquitto через HA
5. Сохранить → вкладка «Информация» → Запустить. Включить «Запускать при загрузке», «Сторожевой таймер», «Показывать в боковой панели»
6. Вкладка «Журнал». Должно быть `Zigbee2MQTT started!` и `Connected to MQTT server`. Если `firmware too old` — см. `03-zigbee.md`, обновление прошивки

Дальше спаривание по `03-zigbee.md`. Каждое спаренное устройство само появляется в HA в Настройки → Устройства и службы → MQTT.

## 3. Полезное, но не обязательное

- **File editor** — правка `configuration.yaml` из браузера. Понадобится для `haos/configuration.yaml`
- **Samba share** — папка `config` видна как сетевой диск с Windows. Удобно для бэкапов и правок
- **Terminal & SSH** — консоль, когда что-то надо посмотреть руками

## 4. configuration.yaml

Через File editor открыть `/homeassistant/configuration.yaml` (в старых версиях `/config/`), заменить содержимое на `haos/configuration.yaml` из этого репо. Там ограничение истории до 7 дней и исключение мусорных сенсоров, чтобы не забивать eMMC. После правки: Настройки → Система → Перезапустить.
