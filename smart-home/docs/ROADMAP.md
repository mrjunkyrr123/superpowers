## Этап 3 — Полезное для бизнеса (капсульный отель)

Это то, ради чего вообще имеет смысл прокачивать этот навык. Домашний стенд — тренировка. Целевая картина:

- **Занятость капсул**: датчик открытия/движения в каждой капсуле → живая карта занятости, реальные данные для аналитики вместо «по бронированиям»
- **Свет и климат по факту присутствия**: пусто — приглушить свет, снизить вентиляцию. Экономия электричества в аэропорту 24/7 — это ощутимые деньги
- **Электронные замки Zigbee** + генерация кода на время брони → заселение без персонала. Это прямое снижение ФОТ
- **Датчики протечки / дыма / температуры** → уведомление в Telegram дежурному
- **Счётчики электричества на розетках** → реальная себестоимость капсулы в час

Железо для этого: SLZB-06M по Ethernet (один на этаж), Zigbee-реле в каждую капсулу, Orange Pi или мини-ПК как сервер на объект.

Для отеля Orange Pi 3 LTS уже слабовата (eMMC, 2 ГБ). Там — мини-ПК Intel N100 за 12-15 тыс. с HAOS. Но логика, конфиги и автоматизации переносятся один в один — поэтому учиться на Orange Pi имеет смысл.
