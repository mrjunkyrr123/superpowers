# Железо: Orange Pi 3 LTS и его ограничения

## Что на борту

| Параметр | Значение | Что это значит для нас |
|---|---|---|
| Процессор | Allwinner H6, 4 ядра Cortex-A53 | Хватает с запасом для HA + Z2M + MQTT |
| Память | 2 ГБ | Нормально. HA ест ~400-600 МБ, Z2M ~100, Mosquitto ~10 |
| Накопитель | 8 ГБ eMMC | **Узкое место.** Система + Docker-образы ~4 ГБ. База HA может вырасти |
| USB | 2× USB 2.0, 1× USB 3.0 | Стик в USB 2.0 — норм. USB 3.0 создаёт помехи для Zigbee 2.4 ГГц |
| Сеть | Gigabit Ethernet + Wi-Fi | **Только провод.** Wi-Fi для сервера умного дома — плохая идея |

## Почему не Home Assistant OS

HAOS — это готовая ОС, где всё ставится кнопкой (Supervisor, аддоны). Официально она есть для Raspberry Pi, ODROID, и нескольких других. **Для Orange Pi 3 LTS её нет.** Есть неофициальные сборки, но они ломаются на обновлениях, и ты будешь чинить систему вместо того, чтобы делать автоматизации.

Вариант «HA Supervised на Debian» тоже отпадает: он поддерживается только на строго определённой конфигурации, Armbian в неё не входит.

**Итого: Armbian + Docker + Home Assistant Container.** Минус: нет магазина аддонов. Плюс: всё, что было аддоном, ставится отдельным контейнером в `docker-compose.yml` — и это, честно, даже прозрачнее.

## Три вещи, которые надо сделать с железом

1. **Ethernet-кабель.** Не Wi-Fi. Zigbee-стик и Wi-Fi платы работают на 2.4 ГГц и мешают друг другу.
2. **USB-удлинитель 0.5–1 м для Zigbee-стика.** Стик, воткнутый прямо в плату, ловит помехи от процессора и USB. Это самая частая причина «датчики отваливаются». Стоит 200 рублей, экономит часы.
3. **Питание 5V/3A через DC-разъём** (не через USB-C от телефонной зарядки). Просадки питания = случайные перезагрузки.

## Про eMMC и износ

eMMC — это флешка. У неё ограниченное число перезаписей. Home Assistant по умолчанию пишет в базу каждое изменение каждого датчика. Поэтому в `configuration.yaml` уже стоит:
- `purge_keep_days: 7` — история хранится неделю
- `commit_interval: 30` — писать на диск раз в 30 секунд, а не каждую секунду
- exclude для мусорных сенсоров (linkquality, last_seen)

Если захочешь историю за месяцы и графики — купи USB SSD (или хотя бы SD-карту класса A2) и перенеси на неё `/var/lib/docker` и папку проекта. Это отдельный шаг, в roadmap.
