# PiPO X10 как панель на стену

X10 это Android-планшет в корпусе с подставкой. Ставим на него одно приложение, которое показывает дашборд HA на весь экран.

## Вариант 1. Приложение Home Assistant (бесплатно, просто)

1. Google Play → «Home Assistant» → установить
2. Открыть, оно само найдёт сервер в сети. Войти под своим пользователем
3. Настройки приложения → Companion app:
   - «Держать экран включённым» — вкл
   - «Полноэкранный режим» — вкл
4. Android → Настройки → Экран → Тайм-аут экрана → максимум или «Никогда»
5. Закрепить приложение: Android → Настройки → Безопасность → Закрепление экрана → вкл. Потом в списке недавних приложений нажать на иконку HA → «Закрепить». Теперь из него не выйти без пин-кода

## Вариант 2. Fully Kiosk Browser (лучше, платный ~700 руб. разово)

Умеет: гасить экран, когда никого нет, и включать по движению перед камерой; отправлять в HA свои датчики (батарея, движение, яркость); удалённо перезагружаться из HA. Для панели на стене это то, что надо.

1. Google Play → «Fully Kiosk Browser» → установить
2. Start URL: `http://<ip-сервера>:8123`
3. Settings → Kiosk Mode → включить, задать PIN
4. Settings → Device Management → Screen Off Timer, Motion Detection (нужна камера)
5. В HA: Настройки → Устройства и службы → Добавить → «Fully Kiosk Browser» → IP планшета и пароль из Fully → Remote Admin. После этого X10 появляется в HA как устройство, и можно из автоматизации гасить ему экран ночью

## Отдельный пользователь для панели

Настройки → Люди → Пользователи → добавить `panel`, **без** прав администратора. На X10 входить под ним. Если панель кто-то потрогает, до настроек сервера он не доберётся.

## Дашборд под панель

Настройки → Панели → Добавить панель → «Новая панель с нуля». Назвать `wall`. Крупные кнопки, свет, температура, ничего лишнего. На X10 открывать именно её: в приложении HA — Настройки → Companion app → Панель по умолчанию; в Fully — Start URL `http://<ip>:8123/wall/0`.
