# Умный дом на Home Assistant

Домашний проект: разобраться с Home Assistant и Zigbee на том железе, что есть.

## Железо

| Роль | Устройство | Почему |
|---|---|---|
| **Сервер** | PiPO X9s (Intel Atom Z8350, 2 ГБ, eMMC 32 или 64 ГБ) | x86 → на него встаёт Home Assistant OS напрямую |
| **Панель на стену** | PiPO X10 (Rockchip RK3399, Android, экран 10") | Тач + Android = готовая панель управления |
| **Zigbee** | Sonoff ZBDongle (P или E, см. `docs/03-zigbee.md`) | Координатор, к нему цепляются все датчики и лампочки |
| В запасе | Orange Pi 3 LTS | Слабее X9s. План Б, см. `docs/06-plan-b-docker.md` |

## Как это работает (для junior)

```
[датчики, лампочки] ~радио~> [Sonoff-стик в X9s] -> [Zigbee2MQTT] -> [Mosquitto] -> [Home Assistant]
                                                                                        |
                                                            [X10 на стене]  <---сеть--->+<---> [телефон]
```

- **Home Assistant OS (HAOS)** — готовая операционка от разработчиков HA. Ставится на X9s вместо Windows. Всё дальше делается кнопками в браузере: аддоны, бэкапы, обновления.
- **Аддон** — это программа, которая ставится внутрь HAOS одной кнопкой. Нам нужны два: Mosquitto (почтовый сервер для сообщений от устройств) и Zigbee2MQTT (переводчик с Zigbee на эти сообщения).
- **X10** просто открывает веб-морду сервера на весь экран. Никаких мозгов на нём нет, это монитор с тачем.
